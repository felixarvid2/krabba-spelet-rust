## Nytt sedan v1.1.0

### Android
- Krabba spelet finns nu som app för Android-telefoner och surfplattor. Ladda ner APK-filen och installera den (du kan behöva tillåta installation från okända källor).
- Spelet körs i liggande läge i helskärm, och bakåtknappen fungerar som Esc.

### Pekskärm
- Styrspak nere till vänster för att gå, och knappar för att använda saker (E), springa och öppna laptopen.
- Tryck direkt i bilden för att gå dit eller använda det du trycker på. Nyp med två fingrar för att zooma.
- ⌨ tar fram telefonens tangentbord i terminalen, med en rad för Tab, ?, piltangenter, Ctrl+C, Ctrl+Z, Ctrl+A K och Enter.
- ☰ öppnar ledtrådar, felrapporten, ärendelistan, handboken, kartan, anteckningar, karriären och hjälpen.
- Pekstyrningen fungerar också när du spelar webbversionen i mobilens webbläsare.
